1. 环境准备

前提条件：服务器已安装 OpenResty（用户已确认），Go 版本为 1.26.3。

1.1 确认 Go 版本

$ go version
go version go1.26.3 linux/amd64

如果版本不是 1.26.3，从 go.dev/dl/ 下载安装：

$ wget https://go.dev/dl/go1.26.3.linux-amd64.tar.gz
$ sudo rm -rf /usr/local/go
$ sudo tar -C /usr/local -xzf go1.26.3.linux-amd64.tar.gz
$ export PATH=$PATH:/usr/local/go/bin
$ go version

1.2 安装 Node.js（全新服务器必做）

如果服务器完全没有 Node.js，按以下步骤安装：

1

安装 Node.js 20 LTS

# 方法一：NodeSource 官方源（推荐，Debian/Ubuntu）
$ curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
$ sudo apt-get install -y nodejs

# 方法二：nvm（支持版本切换）
$ curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash
$ source ~/.bashrc
$ nvm install 20
$ nvm use 20

# 方法三：CentOS/RHEL
$ curl -fsSL https://rpm.nodesource.com/setup_20.x | sudo bash -
$ sudo yum install -y nodejs
2

验证 Node.js 和 npm

$ node --version
v20.19.0        # 20.x 即可，无需特定小版本
$ npm --version
10.8.2

1.3 安装 pnpm 包管理器

pnpm 比 npm 快 2-3 倍，节省磁盘空间。Node.js 16.9+ 自带了 corepack，可以直接启用：

# 方法一：corepack（推荐）
$ sudo corepack enable
$ corepack prepare pnpm@9.15.0 --activate
$ pnpm --version
9.15.0

# 方法二：npm 全局安装（corepack 不可用时）
$ sudo npm install -g pnpm@9.15.0
$ pnpm --version
9.15.0
为什么指定 pnpm 9.15.0？项目的 package.json 中声明了 "packageManager": "pnpm@9.15.0"，使用相同版本可以保证依赖安装的一致性。

1.4 理解 Vue3 + Vite 技术栈（只需安装一次）

新服务器上不需要 "初始化" Vue3 项目——项目的 frontend/ 目录已包含完整的 Vue3 + Vite 工程代码。你只需要在 frontend/ 目录下执行 pnpm install，pnpm 会根据 package.json 自动安装以下内容：

包名类别作用
vue (3.5+)运行时依赖Vue3 框架核心
vue-router (4.5+)运行时依赖前端路由（Hash 模式）
vite (6.2+)开发依赖开发服务器 + 生产构建
@vitejs/plugin-vue开发依赖Vite 的 Vue3 单文件组件插件
typescript (5.7)开发依赖TypeScript 编译器
vue-tsc开发依赖Vue3 TypeScript 类型检查
关键理解：你不需要在新服务器上运行 npm create vue@latest 或 create-vite 来初始化项目——项目已经初始化好了。你只需要 pnpm install 安装依赖，然后 pnpm build 构建即可。

5. 配置 OpenResty

5.1 nginx.conf 完整配置

将此配置文件复制到 OpenResty 配置目录：

worker_processes auto;
error_log /usr/local/openresty/nginx/logs/error.log warn;
pid /usr/local/openresty/nginx/logs/nginx.pid;

events {
    worker_connections 1024;
}

http {
    include       mime.types;
    default_type  application/octet-stream;

    log_format main '$remote_addr - $remote_user [$time_local] "$request" '
                    '$status $body_bytes_sent "$http_referer" '
                    '"$http_user_agent" "$http_x_forwarded_for"';
    access_log /usr/local/openresty/nginx/logs/access.log main;

    sendfile        on;
    keepalive_timeout  65;
    gzip  on;
    gzip_types text/plain text/css application/json
              application/javascript text/xml;

    # ---- 后端 API 上游 ----
    upstream backend_api {
        server 127.0.0.1:34185;
    }

    server {
        listen 80;
        server_name _;

        # 前端静态文件根目录
        root /app/dist;
        index index.html;

        # 静态资源长期缓存（30天）
        location /assets/ {
            expires 30d;
            add_header Cache-Control "public, immutable";
        }

        # API 反向代理到 Go 后端
        location /api/ {
            proxy_pass http://backend_api;
            proxy_set_header Host $host;
            proxy_set_header X-Real-IP $remote_addr;
            proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
            proxy_set_header X-Forwarded-Proto $scheme;
            proxy_read_timeout 60s;
            proxy_connect_timeout 5s;
        }

        # SPA fallback：所有非 API 请求返回 index.html
        location / {
            try_files $uri $uri/ /index.html;
        }
    }
}

5.2 配置说明

配置项作用
listen 80监听 80 端口（HTTP 标准端口）
root /app/dist前端构建产物的存放路径
location /assets/JS/CSS/图片等带 hash 的静态资源，缓存 30 天
location /api/匹配 /api/* 的请求，反向代理到 Go 后端 34185
try_files $uri /index.htmlSPA fallback——URL 刷新时不会出现 404
upstream backend_api定义后端服务地址，方便扩展多个后端实例
gzip on压缩文本类响应，减少带宽消耗

5.4 请求流程

浏览器 → http://服务器:80 │ ├── / → /app/dist/index.html (Vue SPA) ├── /assets/xxx.js → /app/dist/assets/xxx.js (30天缓存) ├── /#/machine-info → index.html (Hash路由由Vue处理) └── /api/machines?... → http://127.0.0.1:34185/api/machines?... (反向代理)
Hash 路由优势：Vue Router 使用 Hash 模式（URL 中有 #），例如 http://服务器/#/machine-info。# 后面的内容不会发送到服务器，完全由浏览器端的 Vue Router 处理。这使得 SPA fallback 配置（try_files）成为可选的安全保障。

8.2 开机自启配置（systemd）

创建 /etc/systemd/system/cmdb-api.service：

[Unit]
Description=CMDB API Service
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/root/workspace/cmdb
Environment="DB_HOST=3418.s.kuaicdn.cn"
Environment="DB_PORT=34189"
Environment="DB_USER=kuaicdn"
Environment="DB_PASSWORD=abcd001002"
Environment="DB_NAME=machine_info"
Environment="DB_SSLMODE=disable"
Environment="JWT_SECRET=9f8e7d6c5b4a3928170605f4e3d2c1b0a9f8e7d6c5b4a3928170605f4e3d2c1b0"
Environment="JWT_EXPIRE=72"
ExecStart=/root/workspace/cmdb/cmdb-api
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target

启用服务：

$ sudo systemctl daemon-reload
$ sudo systemctl enable cmdb-api
$ sudo systemctl start cmdb-api
$ sudo systemctl status cmdb-api
OpenResty 自启：如果通过包管理器安装的 OpenResty，通常已经配置了 systemd 自启。检查：sudo systemctl status openresty。

8.4 防火墙配置

如果服务器有防火墙，确保放行 80 端口：

# iptables
$ sudo iptables -A INPUT -p tcp --dport 80 -j ACCEPT

# firewalld
$ sudo firewall-cmd --add-port=80/tcp --permanent
$ sudo firewall-cmd --reload

# ufw
$ sudo ufw allow 80/tcp

注意：34185 端口（API）不需要对外开放，只通过 127.0.0.1 由 OpenResty 代理访问。

8.5 可选：安装本地 Redis

如果需要缓存功能，安装本地 Redis：

$ sudo apt-get install -y redis-server
$ sudo systemctl enable redis-server
$ sudo systemctl start redis-server
$ redis-cli ping   # 返回 PONG

不安装 Redis 也不影响核心功能——程序在 Redis 不可用时会自动降级，每次请求直接查数据库。

D. 快速启动命令总结（全新服务器，从零开始）

# ==========================================
# 第0步：环境安装（仅首次需要，约5分钟）
# ==========================================

# 安装 Node.js 20
$ curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
$ sudo apt-get install -y nodejs

# 安装 pnpm
$ sudo corepack enable
$ corepack prepare pnpm@9.15.0 --activate

# 验证
$ node --version    # v20.x.x
$ pnpm --version    # 9.15.0
$ go version        # go1.26.3

# ==========================================
# 第1步：获取代码
# ==========================================
$ cd ~/workspace
$ git clone <your-repo-url> cmdb
$ cd cmdb

# 确认 go.mod 版本
$ head -3 go.mod
# go 1.26.3  ← 确认

# ==========================================
# 第2步：构建后端
# ==========================================
$ go env -w GOPROXY=https://goproxy.cn,direct
$ go mod tidy
$ go build -o cmdb-api .

# ==========================================
# 第3步：构建前端
# ==========================================
$ cd frontend
$ pnpm install      # 安装 vue/vite/vue-router 等依赖
$ pnpm build        # vite build → dist/
$ sudo mkdir -p /app/dist
$ sudo cp -r dist/* /app/dist/
$ cd ..

# ==========================================
# 第4步：配置并启动 OpenResty
# ==========================================
$ sudo cp openresty/nginx.conf /usr/local/openresty/nginx/conf/nginx.conf
$ sudo /usr/local/openresty/bin/openresty -t
$ sudo /usr/local/openresty/bin/openresty -s reload || sudo /usr/local/openresty/bin/openresty

# ==========================================
# 第5步：启动 Go API
# ==========================================
$ export DB_HOST=3418.s.kuaicdn.cn DB_PORT=34189 DB_USER=kuaicdn DB_PASSWORD=abcd001002
$ export DB_NAME=machine_info DB_SSLMODE=disable
$ export JWT_SECRET=9f8e7d6c5b4a3928170605f4e3d2c1b0a9f8e7d6c5b4a3928170605f4e3d2c1b0 JWT_EXPIRE=72
$ nohup ./cmdb-api > /var/log/cmdb-api.log 2>&1 &

# ==========================================
# 第6步：验证
# ==========================================
$ curl http://localhost:80/                          # 应返回 index.html
$ curl -s -X POST http://localhost:80/api/login \    # 应返回 token
    -H "Content-Type: application/json" \
    -d '{"username":"admin","password":"cbh7cyf.vcn!tuy_MUD"}'
