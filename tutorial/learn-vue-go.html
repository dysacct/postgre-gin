第1章 Vue3 基础：模板语法与响应式

1.1 单文件组件结构

Vue3 的每个 .vue 文件（SFC，Single File Component）包含三部分：

<script setup lang="ts">   // 逻辑（TypeScript）</script>
<template>                  // 模板（HTML）</template>
<style scoped>              // 样式（仅作用于当前组件）</style>
script setup 是 Vue3.2+ 引入的语法糖。在此模式下，所有顶级变量自动暴露给模板，无需手动 return。不需要像 Vue2 那样写 export default { data() {}, methods: {} }。

第2章 Vue3 核心：ref / reactive / computed / watch

2.1 ref — 响应式基础类型

ref 包装一个值使其变为响应式。在 <script setup> 中，模板自动解包，不需要 .value：

import { ref } from 'vue'

const loading = ref(false)         // boolean
const searchText = ref('')         // string
const page = ref(1)                // number
const list = ref<any[]>([])        // 数组

// 脚本中访问/修改需要 .value
loading.value = true
page.value++

// 模板中自动解包，直接使用
// <button :disabled="loading">

2.2 reactive — 响应式对象

reactive 将一个对象变为深度响应式。适合表单数据：

import { reactive } from 'vue'

const filters = reactive({
  idc_code: '',
  ip_status: '',
  net_type: '',
  ipmi_ip: '',
})

// 脚本中直接读写属性（不需要 .value）
filters.idc_code = 'B11'

// 重置所有字段
Object.keys(filters).forEach(k => (filters as any)[k] = '')
ref vs reactive 的选择：基础类型用 ref，对象/数组用 ref 或 reactive。但 reactive 不能直接替换整个对象（会丢失响应式），用 ref 更安全：const filters = ref({...})。

2.3 computed — 计算属性

自动缓存，依赖变化时才重新计算：

const totalPages = computed(() => Math.ceil(total.value / size.value) || 1)

const filteredList = computed(() => {
  if (showUnknown.value) return list.value
  return list.value.filter(item => item.business_info?.business_name !== '未知业务')
})

// 使用：绑定到模板 {{ totalPages }} / {{ filteredList }}

2.4 watch — 监听变化

主动观察某个值的变化并执行副作用：

import { watch } from 'vue'

// 监听单个 ref
watch(searchText, (newVal) => {
  console.log('搜索文本变化:', newVal)
})

// 监听多个值
watch([idcCode, ipmiIP], () => {
  page.value = 1    // 搜索条件变化时重置页码
  fetchData()
})

4.2 路由守卫

// 全局前置守卫：每次导航前执行
router.beforeEach((to, _from, next) => {
  const token = localStorage.getItem('token')

  if (to.name !== 'Login' && !token) {
    next({ name: 'Login' })     // 未登录 → 强制跳转登录
  } else if (to.name === 'Login' && token) {
    next({ path: '/' })         // 已登录 → 访问/login时重定向首页
  } else {
    next()                       // 放行
  }
})
执行流程：用户访问 /#/machine-info → beforeEach 检查 token → token 不存在 → 重定向到 /#/login → 用户登录成功 → router.push('/') → 重定向到 /machine-info。

第8章 Go 进阶：Struct / Method / Interface / 嵌入

8.1 Struct 与 Tag

type User struct {
    ID           uint      `gorm:"primaryKey"`                          // GORM tag
    Username     string    `gorm:"unique;not null;size:50" json:"username"`  // GORM + JSON tag
    PasswordHash string    `gorm:"column:password_hash;not null"`
    Role         string    `gorm:"size:20;default:user"`
    CreatedAt    time.Time `gorm:"autoCreateTime"`
}

func (User) TableName() string {    // 方法：指定表名
    return "users"
}

Struct tag 是 Go 的元数据机制。反引号中的字符串由特定库解析：gorm 定义数据库列属性，json 定义序列化字段名。

8.2 方法（带接收者的函数）

// 值接收者：不修改原 struct（只读）
func (u User) IsAdmin() bool {
    return u.Role == "admin"
}

// 指针接收者：可以修改原 struct
func (u *User) SetPassword(hash string) {
    u.PasswordHash = hash
}

// 调用
user := User{Role: "admin"}
fmt.Println(user.IsAdmin())    // true
user.SetPassword("new_hash")   // 修改 user 的 PasswordHash

8.3 Interface — 隐式实现

// 定义接口
type Writer interface {
    Write(p []byte) (n int, err error)
}

// 任何有 Write 方法的类型自动实现了 Writer
// 不需要显式声明 "implements"
type MyWriter struct{}
func (m MyWriter) Write(p []byte) (int, error) {
    return len(p), nil
}

// 多态使用

w.Write([]byte("hello"))

}()

// 主 goroutine 等待信号
stop := make(chan os.Signal, 1)
signal.Notify(stop, os.Interrupt, syscall.SIGTERM)
<-stop   // 阻塞直到收到 Ctrl+C
关键：main 函数结束时，所有 goroutine 都会被强制终止。所以主 goroutine 必须等待其他 goroutine 完成（通过 channel 或 WaitGroup）。

9.2 Channel — goroutine 间通信

// 无缓冲 channel：发送方阻塞直到有接收方
done := make(chan bool)
go func() {
    doWork()
    done <- true    // 发送完成信号
}()
<-done              // 等待接收

// 带缓冲 channel
results := make(chan int, 10)   // 缓冲 10 个，发满之前不阻塞

// 信号 channel（main.go）
stop := make(chan os.Signal, 1)
signal.Notify(stop, os.Interrupt)  // 操作系统信号会发送到 stop channel

11.3 事务

tx := db.Begin()          // 开启事务
if tx.Error != nil { return }

// 一系列操作...
if err := tx.Create(&record).Error; err != nil {
    tx.Rollback()          // 任何一步失败 → 全部回滚
    return
}
if err := tx.Delete(&item).Error; err != nil {
    tx.Rollback()
    return
}

tx.Commit()               // 全部成功 → 提交
事务要点：每个操作后检查 error，失败时 Rollback。成功时必须 Commit。如果函数返回但未 Commit 也未 Rollback，连接不会归还连接池，造成连接泄露。

12.1 bcrypt 密码哈希

import "golang.org/x/crypto/bcrypt"

// 加密（不可逆）
func hashPassword(password string) string {
    hash, err := bcrypt.GenerateFromPassword([]byte(password), bcrypt.DefaultCost)
    if err != nil { log.Fatal(err) }
    return string(hash)
}

// 验证
if err := bcrypt.CompareHashAndPassword([]byte(user.PasswordHash), []byte(req.Password)); err != nil {
    // 密码不匹配
}

bcrypt.DefaultCost = 10，表示 2^10 = 1024 轮哈希迭代。越大越安全但越慢。10 是平衡的选择。

12.2 JWT 生成与验证

import "github.com/golang-jwt/jwt/v5"

type Claims struct {
    Username string `json:"username"`
    Role     string `json:"role"`
    jwt.RegisteredClaims              // 标准声明：过期时间、签发时间、签发者
}

// 生成
func GeneratoToken(username, role string) (string, error) {
    claims := Claims{
        Username: username,
        Role:     role,
        RegisteredClaims: jwt.RegisteredClaims{
            ExpiresAt: jwt.NewNumericDate(time.Now().Add(72 * time.Hour)),
            IssuedAt:  jwt.NewNumericDate(time.Now()),
            Issuer:    "gin-postgre-api",
        },
    }
    token := jwt.NewWithClaims(jwt.SigningMethodHS256, claims)
    return token.SignedString(jwtSecret)
}

// 验证
func ValidateToken(tokenString string) (*Claims, error) {
    claims := &Claims{}
    token, err := jwt.ParseWithClaims(tokenString, claims,
        func(t *jwt.Token) (interface{}, error) {
            return jwtSecret, nil   // 提供密钥用于验证签名
        })
    if err != nil || !token.Valid {
        return nil, err
    }
    return claims, nil
}
JWT 不能吊销：JWT 一旦签发，在过期前始终有效。如果用户修改密码或账号被禁用，已有的 token 仍然可用。解决方案：(1) 短过期时间，(2) Redis 维护黑名单，(3) 服务端 session。
