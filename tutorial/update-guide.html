1. 关键修复：Redis 空指针崩溃（CRITICAL）

影响范围：服务器没有 Redis 时，所有 API 调用触发 panic → 500 空响应 → 前端 JSON 解析失败。删除管理、机器查询、网络操作全部不可用。

1.1 根因

database/redis.go 中 ConnectRedis() 连接失败时设置 RedisClient = nil。但所有 handler 直接调用 database.RedisClient.Get() / .Set() / .Del() / .FlushDB()，nil 指针上调用方法 → panic。

1.2 修复方案

在 database/redis.go 新增 4 个 nil-safe 包装函数：

// Redis 不可用时返回空结果（redis.Nil）
func CacheGet(ctx context.Context, key string) *redis.StringCmd {
    if RedisClient == nil { return redis.NewStringResult("", redis.Nil) }
    return RedisClient.Get(ctx, key)
}

// Redis 不可用时静默跳过
func CacheSet(ctx context.Context, key string, value interface{}, ttl time.Duration) {
    if RedisClient == nil { return }
    RedisClient.Set(ctx, key, value, ttl)
}

func CacheDel(ctx context.Context, keys ...string) {
    if RedisClient == nil { return }
    RedisClient.Del(ctx, keys...)
}

func CacheFlushDB(ctx context.Context) {
    if RedisClient == nil { return }
    RedisClient.FlushDB(ctx)
}

结果：Redis 不可用时所有 API 正常响应，缓存降级为直接查库，不再 panic。

2. 新增功能：Excel 导出

所有 5 个页面添加绿色"导出Excel"按钮，服务端使用 excelize 库生成 .xlsx 文件。

2.1 导出路由

GET /api/machines/export        # 机器信息（支持 search/idc_code/business_name 过滤）
GET /api/network-info/export     # 网络信息（支持 idc_code/ip_status/net_type 过滤）
GET /api/business-info/export    # 业务信息（支持 business_name/idc_code 过滤）
GET /api/idc_info/export         # SSH信息（全量）
GET /api/deletion/records/export # 删除记录（支持 record_type 过滤）

2.2 前端实现

api/index.ts 新增 downloadExport()：用 fetch() 带 Bearer token 请求 → 收到 blob → URL.createObjectURL → 触发下载。因为 <a download> 标签无法设置 Authorization header。

3. 新增功能：删除管理

  • 删除机器信息（三表） — 按机房编码或 IPMI IP 列表删除 idc_info + machine_info + business_info，归档到 deleted_records 保留 30 天
  • 删除网络信息（单表） — 按机房编码或 IPMI IP 列表删除 network_info，归档保留 30 天
  • 弹框确认 — 点击删除按钮弹出模态框，展示将要删除的目标，确认后执行删除，可取消
  • 已删除记录查看 — 机器 tab 显示 ZbxID / IPMI IP / 机房编码 / 机房名称 / SSH IP / 操作人 / 删除时间 / 剩余天数；网络 tab 显示完整网络字段
  • 自动清理 — 每 12 小时清理一次 expired_records，到期数据自动删除
删除页表格简化：机器 tab 之前尝试显示硬件列（系统类型、厂商、CPU、内存、系统盘、SSD、HDD、高度、序列号），但 machine_info 表这些字段多为空值。现简化为 8 列：ZbxID / IPMI IP / 机房编码 / 机房名称 / SSH IP / 操作人 / 删除时间 / 剩余天数。

4. 改进：网络统计卡片

NetworkInfo.vue 顶部统计卡片现在显示清晰的标签：

  • 第 1 张卡片：网络记录总数 / 全量
  • 第 2-9 张卡片：机房 XXX / 网络记录数
  • 从 6 张扩展为 9 张，展示 top 8 机房 + 全量

5. 改进：删除确认弹框

删除按钮不再需要输入"确认删除"文字，改为点击按钮 → 弹出模态框 → 展示删除目标 → 确认/取消。更直观、更安全。

8. 清空数据 SQL

-- 清空所有业务数据（表结构保留）
TRUNCATE TABLE idc_info, machine_info, business_info, network_info, deleted_records CASCADE;

-- 或用 DELETE（支持 WHERE 条件）
DELETE FROM business_info;
DELETE FROM machine_info;
DELETE FROM network_info;
DELETE FROM idc_info;
DELETE FROM deleted_records;
注意：这些操作不可逆。TRUNCATE 比 DELETE 快得多，但不能回滚（在 PostgreSQL 中 TRUNCATE 是事务安全的，可以 ROLLBACK）。
